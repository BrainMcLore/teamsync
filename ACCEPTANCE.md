# Приёмка

## Первый срез — ожидаемые автоматические проверки

- SQLite: создание команды/участника/карты/тактики/задания, повторное открытие файла.
- История: атомарная версия и восстановление содержимого.
- Изоляция: нельзя привязать к заданию участника или тактику другой команды.
- Задания: допустимые переходы и отклонение неправильных.
- RU/EN: совпадение ключей ARB и параметров, переключение UI без потери редактора.
- UI: desktop 1366×768, mobile 390×844, пустые состояния и длинные названия.
- Нативная Windows сборка и запуск.

Результаты фактического запуска проверок записываются в CHECKS.md.

## Полный релиз

Все 21 сквозных сценария из раздела 24 исходного ТЗ обязательны. В частности реальные OAuth, несколько пользователей, чужая команда, потеря сети, настоящий парсер, повреждённая демка, PDF, авиарежим, отзыв агента и backup restore. До выполнения они имеют статус «не проверено», не «готово».
