# Отчёт проверки TeamSync 0.1.0

Дата: 2026-10-28. Это ранняя рабочая версия. Полное ТЗ **не завершено**.

## Подтверждено

- `flutter analyze --no-pub`: ошибок и предупреждений нет.
- `flutter test --no-pub`: **20 тестов прошли**. SQLite и повторное открытие файла, версии и конфликты, привязки внутри команды, статусы заданий, ARB-ключи и параметры, переключение языка без потери команды, offline export/import и rollback, HTTP token handling и запрет redirect, PDF с кириллицей, размеры интерфейса, нормализованные координаты радара.
- `python -m pytest server/tests -q`: **6 тестов прошли**. Проверены серверные права, отзыв членства, приглашения, версии, идемпотентность, история, PKCE и одноразовые коды, сессии, передача владения, привязка провайдера к существующему user_id. Ответ внешнего провайдера в этих тестах моделируется; это не реальная OAuth-проверка.
- Нативная Windows release сборка с C++ plugins: успешна. Приложение запущено отдельным окном, русский стартовый экран визуально проверен.
- Установщик Inno Setup собран. Тестовая установка в `.tools/install-smoke`: exit code 0. У установленного процесса появилось окно `TeamSync`. Визуальная проверка именно установленной копии прервана пользователем клавишей Escape; дальнейшее управление UI прекращено.
- Android debug и release-сборки APK: успешны. Release использует **тестовую debug-подпись**, не магазинный ключ. На физическом телефоне пока не проверено.
- Проверены размеры Flutter UI: 1366×768, 390×844 и 320×640, русский и английский, длинные названия, пустые состояния и карточки заданий. Это widget tests, не проверка физических Android/iPhone устройств.
- PDF ru/en с пользовательским кириллическим содержимым сгенерированы и просмотрены через Poppler. Текст, отступы и номера страниц читаемы. Верификационные PDF в artifacts/verification — тестовые материалы, не предустановленные данные продукта.
- Пакеты сохраняют только текущие версии тактик, не всю историю. Импорт создаёт новую локальную команду и новые UUID; существующие команды не перезаписываются. Повреждённый пакет откатывается.

## Известные ограничения и дальнейшая проверка

Нет расписания, раскидок, review timeline, серверного агента, push, аналитики навыков и полного LAN-манифеста. Редактор пока не поддерживает все типы объектов и операции из ТЗ. Пользовательские карты импортируются вручную; официальные радары не включены без проверки прав.

Физические телефоны, landscape/safe areas, Windows масштабирование и 1920/2560, реальный OAuth, PostgreSQL и Docker deployment, конкурентные запросы и нагрузка требуют отдельной приёмки. iOS проект подготовлен, но сборка на Windows невозможна. Подпись Windows и магазинная Android/iOS дистрибуция не выполнялись.

API использует начальную схему SQLAlchemy и поставляет DDL `server/migrations/001_initial_postgresql.sql`; последующие миграции и полноценная production эксплуатация ещё не готовы. Rate limiting и HTTPS должны обеспечиваться настроенным reverse proxy. Тестовый HTTP-клиент FastAPI сообщает deprecation предупреждение httpx, сами API-тесты проходят.
