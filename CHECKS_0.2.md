# TeamSync 0.2 — отчёт проверки

Дата: 2026-10-29. Предыдущий отчёт сохранён в CHECKS_0.1.md. Версия 0.2 закрывает готовые карты, переработку интерфейса и базовый нативный импорт/разбор DEM, а не всё исходное ТЗ.

## Подтверждённые проверки

- Flutter: **25 тестов проходят**, анализатор без ошибок и предупреждений. В том числе обновление реальной схемы поставленной версии 0.1, готовые карты и координаты, этажи Nuke, перенос нижнего радара в offline package, версии, задачи, RU/EN, интерфейс на 320/390/1366, desktop/mobile 2D-разбор и native process bridge.
- Python: **10 тестов проходят** — 6 API и 4 worker. Проверены path traversal, symlinks, локальные адреса для загрузки, недопустимый источник, повреждённый DEM, ZIP deflate, stored RAR4 и настоящий CS2 parser fixture. Интеграционный fixture доступен из закреплённого upstream commit и проверяется по SHA-256.
- Реальный файл 60 601 900 байт, SHA-256 `84a1a4191302bdd2a3bbb5a727842093744b1fb1a228aeec630369e44b622cb2`: карта Mirage, 10 игроков, 10 раундов, 73 события убийства, 3544 снимка, измеренная частота 64 tick/s. Это открытая Valve matchmaking-фактура из тестов demoparser, **не заявляется HLTV-матчем**.
- Упакованный самостоятельный `teamsync-demo.exe` обработал DEM и RAR с реальной записью. Flutter DemoJob вызвал этот бинарник, сохранил результат и при повторном импорте вернул ту же запись. Существующая запись из 0.1 обновляется, не копируется ради игроков.
- Worker использует OS Job Object: ограничение памяти 2 ГБ на процесс, до 4 процессов в группе, завершение дочернего extractor при закрытии worker. Клиент ограничивает задачу 8 минутами. Схема не меняет процесс игры.
- Готовый набор: **9 карт, 12 радаров с этажами, 9 обложек**, manifest/source revision и контрольные суммы. Повторное добавление в команду не создаёт дубликаты. Собственные радары не заменяются. Преобразование координат Mirage и выбор этажей Nuke проверены; позиции реальной Mirage-записи визуально соответствуют областям T/CT spawn.
- Проверочные PNG `artifacts/verification/studio-*-02.png` получены рендером настоящих Flutter-экранов с Inter и реальными игровыми изображениями. Проверены карты, редактор, мобильное задание, desktop и mobile review. Состав QA существует только в тестах, не добавляется пользователю.
- Windows secure-storage adapter: убрана зависимость от ATL только в преобразовании строк, сохранены кодовая страница и upstream криптография. Нативный C++ smoke test реально записал/прочитал Unicode QA-значение в Credential Manager, проверил перечисление и удалил свою QA-запись. Настройки безопасности Windows не менялись.
- Windows release и Android release APK собираются. Windows installer включает карты, parser runtime, 7-Zip и notices. Android использует тестовую debug-подпись; магазинная публикация не выполнялась.

## Работающий пользовательский сценарий

Команда → готовая карта/этаж → тактика/версия → задание. Windows: файл/публичная прямая ссылка → распаковка → parser → одна запись карты со всеми игроками → раунды, позиции/взгляд/здоровье, события/KDA, перемотка/скорость, точки smoke/molotov по реальным событиям → заметка на тике → задание с контекстом записи. `.teamsync-review` переносится на телефон и открывается без исходного DEM.

При переходе между разделами worker продолжает импорт. При отмене процесс завершается; незакреплённый job-каталог и повторно скачанный дубликат удаляются только из собственного UUID-каталога кэша.

## Что не следует считать проверенным

- Автоматический каталог или scraping HLTV не подключены. Поддержаны скачанный пользователем файл, прямая публичная HTTPS-ссылка и ручная ссылка матча. HTML/403/CAPTCHA ведут к запасному пути через браузер. Защита не обходится, cookies не заимствуются. Живое скачивание защищённого HLTV URL не проверялось.
- Совместимость со всеми версиями CS2 и точная геометрия всех старых карт не гарантируются. Один настоящий DEM проверен; нужны дополнительные записи с разных карт и современных турниров. Радары и calibration имеют фиксированный revision, UI предупреждает о возможных отличиях геометрии.
- Воспроизведение дискретное, обычно 4 снимка/с; нет выдуманных промежуточных позиций. Полная геометрия дыма/огня, видимость противника и реальный полёт гранаты не моделируются. Показаны записанные точки событий.
- Автоматический запуск самой CS2, сопряжение телефона с ПК, серверный worker для mobile, полный матчевый каталог/фильтры всех полей и готовые профессиональные подборки пока не реализованы.
- Реальные Steam/Discord входы, физические телефоны, iOS compilation, Windows text scaling и production PostgreSQL/Docker по-прежнему требуют отдельной проверки. Полный исходный набор сценариев ещё не принят.
- Расписание, раскидки, полная совместная синхронизация, push, буткемп, server agent и production-релиз остаются в ROADMAP.md. API tests моделируют доверенный ответ OAuth-провайдера, а не живой вход.
