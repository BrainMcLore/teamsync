# TeamSync 0.5 — встроенная загрузка HLTV

Дата: 2026-10-29. Отчёт 0.4 сохранён в CHECKS_0.4.md.

Внешний браузер и наблюдение за Downloads удалены из основного сценария. При JS-проверке источника HTTP-загрузка переходит к отдельному нативному сетевому помощнику Microsoft WebView2. Он использует собственный профиль, сохраняет архив в папку задания, передаёт прогресс и отменяется вместе с заданием. Основной интерфейс остаётся Flutter. При необходимости показывается окно проверки источника; автоматического решения CAPTCHA нет.

Реальная проверка: HLTV download/demo/113273, матч Vitality — Natus Vincere, PGL Masters Bucharest 2026. RAR5: 617 663 073 байта, проверка 7-Zip успешна, три DEM общим размером 943 856 924 байта. Загрузка, распаковка и разбор успешно завершились: Cache, Mirage, Dust2, по десять игроков. Логи: artifacts/verification/native-download-probe.log и managed-chain-05.log. Записи находятся только в служебных QA-папках и не поставляются с программой.

Помощник принимает HTTPS HLTV/CDN, блокирует посторонние переходы/окна/разрешения, не перезаписывает существующий файл, ограничивает архив 2 GiB, проверяет свободное место и таймаут. Подпись официального установщика WebView2 проверяется при сборке. Установщик TeamSync добавляет runtime, если он отсутствует. Лицензия SDK поставляется с программой.

34 Python-теста проходят. Flutter-анализатор: No issues found. Живая проверка готового worker: TEAMSYNC_LIVE_HLTV=1, client/test/managed_hltv_05_test.dart. Обычные тесты не зависят от доступности HLTV.

Android/iOS используют подготовленные разборы, Windows-помощник на них не запускается. APK имеет тестовую подпись. iOS на Windows не собирался. Полная установка CS2 и LAN-матч повторно не проверялись; предыдущие результаты — CHECKS_0.4.md. Доступность стороннего источника может меняться.

Готовый автономный worker также проверен через настоящий DemoJob и временную SQLite-библиотеку: живая загрузка за 35 секунд завершилась тремя картами и 10 игроками на каждой, размер архива совпал. Лог: artifacts/verification/live-frozen-05.log. 44 обычных Flutter-теста проходят; живой сетевой тест выполняется отдельно и по умолчанию пропускается.

Windows Release 0.5.0+5 и Inno Setup собраны успешно. Runtime обнаружен через поставляемый helper --check-runtime (exit 0). Android release test APK собран; apksigner verify подтвердил v2-подпись. Source ZIP проверен на целостность, не содержит DEM или служебные SDK.
