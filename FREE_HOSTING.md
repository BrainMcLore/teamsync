# Постоянный бесплатный тариф: Render + Neon

Проверено по документации 2026-10-29. Это бесплатные тарифы с лимитами, без заранее заданного 30-дневного срока базы. Условия провайдеров могут измениться; бессрочную бесплатность обещать нельзя.

- API: Render Free Web Service, европейский регион Frankfurt, штатный HTTPS-адрес `*.onrender.com`, собственный домен покупать не требуется.
- Данные аккаунтов, сессий, составов и приглашений: отдельный Neon Free PostgreSQL. Бесплатная база Render не используется — она истекает через 30 дней.
- DEM, радары и пользовательские файлы остаются в приложении. Бесплатную базу не заполняем архивами демок.
- После 15 минут простоя Render засыпает. Первый запрос может ждать около минуты; клиент повторяет только безопасную проверку подключения. Нет искусственного постоянного пинга.

## Размещение

1. Войти/зарегистрироваться в [Neon](https://console.neon.tech/) и создать Free-проект в Европе. Скопировать pooled connection string с `sslmode=require`. Хранить её только в настройках сервера, не в приложении и не в Git.
2. Поместить содержимое Server ZIP в свой GitHub-репозиторий. Архив содержит только API и Render Blueprint, без локальных баз и секретов.
3. В [Render](https://dashboard.render.com/) выбрать New → Blueprint, подключить репозиторий. `render.yaml` уже задаёт Free, Frankfurt, Python, health-check и запуск.
4. Ввести `DATABASE_URL` из Neon. Для входа через Steam отдельный API key не нужен. Discord можно подключить следующим шагом, оставив обе переменные Discord пустыми, если кабинет позволяет пустое значение.
5. Дождаться успешного deploy. `PUBLIC_URL` автоматически берётся из публичного имени Render; при другом хостинге задать полный HTTPS origin вручную. Проверить `/api/v1/health`: status=ok, providers.steam=true. Производственный запуск откажется работать с временной SQLite вместо PostgreSQL.
6. Создать приложение в [Discord Developer Portal](https://discord.com/developers/applications). OAuth2 redirect: `https://ИМЯ.onrender.com/api/v1/auth/discord/callback`. Client ID и Client Secret добавить только в Render Environment и перезапустить сервис. Проверить providers.discord=true.
7. В TeamSync → Настройки → Онлайн-аккаунт указать полученный HTTPS-адрес. На Windows и телефоне использовать один сервер. Можно собрать клиент с `--dart-define=TEAMSYNC_API_URL=https://ИМЯ.onrender.com`, чтобы адрес уже был заполнен.

Вход, создание новых учётных данных и принятие условий сервисов выполняет владелец аккаунта. Карта и платные тарифы для этого варианта не предусмотрены; если сервис предлагает оплату, выбирать Free либо остановить регистрацию.

## Состав

После входа скопировать ID в профиле. Владелец команды открывает её состав → «Пригласить по аккаунту», вводит ID игрока и подтверждает найденный аккаунт. Игрок принимает приглашение в своём профиле. Без его согласия членство не создаётся. Доступны срок/отзыв приглашений, права, игровая роль, основной/запасной/штаб, выход, удаление и передача владения. «Добавить состав в рабочую область» сохраняет снимок аккаунтов с устойчивыми локальными ID; тактики и радары синхронизируются автоматически, демки и PDF остаются локальными.

## Проверки после размещения

Войти настоящими Steam/Discord аккаунтами с Windows и Android; проверить возврат из браузера и перезапуск приложения, отзыв сессии с другого устройства, приглашение/принятие/удаление между двумя аккаунтами. Проверить пробуждение сервера после простоя. Локальные тесты с имитацией ответов провайдеров не считаются этой живой приёмкой.
