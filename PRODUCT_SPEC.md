# TeamSync — спецификация продукта

Нативные клиенты Flutter для Windows, Android, iOS. Веб-клиент, PWA и WebView не входят в продукт. Полное исходное ТЗ: [TeamSync_requirements_RU_EN.md](TeamSync_requirements_RU_EN.md).

## Первый проверяемый срез

Пользователь создаёт локальную команду, добавляет участников и карту, создаёт тактику, рисует объекты на собственном плане карты, сохраняет версии, назначает связанное задание и меняет его состояние. После закрытия данные восстанавливаются из SQLite. Русский и английский доступны без сети. Локальная рабочая область явно отделена от будущей общей команды на сервере.

Основной цикл: карта → тактика → задание → сдача → проверка. Пользовательские названия и заметки не переводятся.

## Полный продукт

Все 25 разделов исходного ТЗ обязательны для релиза. Реализация отдельного среза не означает готовность всего продукта. Неподключённые сервисы не имитируются. Серверная авторизация, синхронизация, парсинг демок, PDF, push, серверный агент и магазинные релизы принимаются отдельно.

## Уточнение пользователя 2026-10-29

Пользователь явно заменил ограничение исходного ТЗ по HLTV: нужен прямой парсинг каталога для удобной загрузки и просмотра. В 0.4 реализован on-demand catalog reader с реальными результатами/деталями, cache, direct Demo-link и браузерным приёмом при блокировке CDN. Также запрошены и добавлены производительность playback и загрузка CS2/TS3 server files внутри приложения. Личные аккаунты/cookies не импортируются. Это не обещание гарантированного обхода любых проверок сайта.
