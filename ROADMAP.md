# План реализации

Статусы обновляются только после проверки. Полный релиз пока не готов.

## Следующий срез — в работе

- Изоляция локального кеша по серверу и аккаунту, обработка истёкшей сессии.
- Командная синхронизация заданий с назначениями по аккаунтам, связью с тактиками и серверными правами сдачи/подтверждения.
- Автоматическая проверка Android на эмуляторе, постоянная подпись и сборка APK в CI.
- Базовая общая библиотека раскидок: источники YouTube/CS2Tricks, инструкции, карта/сторона и связи с тактиками; свои изображения и MP4 добавлены, статусы изучения ещё впереди.
- Переработанный README с возможностями, ограничениями и воспроизводимыми командами сборки.
- Ещё не завершены все функции исходного ТЗ и полная игровая приёмка; публичный выпуск не объявлен.

## Версия 0.8 — исправления и выпуск

- Исправлена UTF-8 отправка русских тактик/заметок, убрано создание локальных команд из UI.
- Каталог и карточки HLTV используют изолированный Windows WebView2-сеанс при блокировке HTTP.
- Windows/Android 0.8 собирались и проверялись перед переносом среды; итоговые артефакты и их наличие учитываются отдельно в RELEASE.md.
- Linux — только среда разработки; Linux-приложение не является целью.

## Версия 0.7 — общие тактики

- Одна командная библиотека схем/заметок/сторон/этажей/радаров на сервере, права записи и чтения.
- Windows/Android: автоматическая синхронизация, durable outbox, идемпотентные повторы, конфликтные копии, обновление открытого редактора.
- Проверено двумя аккаунтами и на Android; демки/задания/PDF пока локальны.

## Версия 0.6 — аккаунты и Android

- Опубликован общий API с постоянной PostgreSQL-базой Neon Free и Render Free. Steam/Discord настроены, секреты только на сервере.
- Приглашения конкретным аккаунтам, принятие/отклонение, роли/составы, выход/удаление/передача владения, управление сессиями.
- Восстановление Android PKCE/deep-link, защищённое хранение; проверено на эмуляторе Android 15. Настоящий телефон и живой Steam-вход требуют приёмки.
- Общая библиотека тактик в рабочей области: схемы, заметки, этажи, радары; офлайн-очередь, повторная отправка и конфликтные копии.

## Версия 0.4 — реализовано, проверки в CHECKS.md

- Чтение/индексация demo вне UI, cache, двоичные запросы событий, Ticker/repaint и визуальное сглаживание между снимками; проверка на существующей записи пользователя без её изменения.
- Реальный HLTV catalog на Windows: results pagination, cache, details/Demo-link, фильтры и ручная классификация событий, browser-download bridge при ограничении CDN.
- Встроенная загрузка CS2 Dedicated Server через официальный SteamCMD (resume, self-update retry) и TS3 из official pinned ZIP. TS лицензия читается/принимается внутри UI. Полная CS2 загрузка и живой LAN-сеанс ещё требуют приёмки.

## Версия 0.3 — реализовано, проверки в CHECKS.md

- Cache в готовом наборе; отдельные T/CT и читаемые печатные символы.
- Заметки демо с кликабельными метками времени, ручная разметка и фильтры команд/позиций/тира, приём новой загрузки HLTV из выбранной папки браузера.
- Подготовка DEM и запуск через Steam; живое playdemo требует проверки.
- Конструктор PDF-страниц раундов со снимками конкретной версии тактики, RU/EN.
- Локальный Windows-буткемп: собственные процессы CS2/TS3, A2S/Query, установка закреплённых MatchZy/CounterStrikeSharp/Metamod с SHA и backup; PUG/practice, матч JSON/veto, фиксированные RCON-команды. Установщик проверен в тестовом дереве; настоящий игровой/голосовой LAN-сеанс ещё не принят.

## Версия 0.2 — выполнено

- Новый Flutter studio shell, Inter, поиск, библиотека обложек, превью тактик, доска заданий, переработанные desktop/mobile экраны.
- Готовые карты и этажи с версией, SHA-256 и обзорной калибровкой, автоматическое добавление команде, сохранение своих материалов.
- Нативный Windows demo companion: DEM / ZIP / RAR / public HTTPS, прогресс/отмена, изоляция, SHA-256 dedup, события/игроки/снимки, 2D-раунды, заметки и задача из заметки.
- Подготовленный `.teamsync-review` для просмотра на телефоне; исходные DEM на телефоне не парсятся.
- Поставляемый source/runtime adapter Windows secure storage без ATL, с реальным Credential Manager smoke test.
- Фактические результаты и ограничения: CHECKS.md.

1. Реализован первый локальный срез: нативный проект, RU/EN, SQLite, команда и состав, карты, базовый редактор, история, задания, импорт локальных демок, PDF, перенос текущих материалов. Windows installer и Android test APK собираются. Проверки и ограничения — CHECKS.md.
2. Реализован фундамент backend identity/teams, Steam OpenID и Discord OAuth flows, сессии, приглашения, изоляция команд и аудит. Native UI подключён к аккаунту и онлайн-командам. Реальные провайдеры, PostgreSQL и несколько пользователей ещё не приняты; этот этап не завершён.
3. Синхронизация двух клиентов: outbox, идемпотентность, версии и конфликтные копии реализованы. Используется периодическое обновление; WebSocket пока не реализован.
4. Раскидки с собственными изображениями и MP4, статусами изучения и проверкой тренером добавлены в исходники. Остались расписание, комментарии к расширенным заданиям и push.
5. Расширить работающие PDF и экспорт/восстановление до полного LAN-пакета: выбор карт/состава, полнота, история, разрешённые медиа и prepared demo data.
6. Расширить работающий parser/review: больше настоящих современных демок с разных карт, дополнительная проверка геометрии, полный timeline и аннотации, download resume/cache management, согласованный источник каталога, проверенный запуск CS2.
7. Живая приёмка локального буткемпа с CS2/MatchZy/TS3, дальнейший ограниченный удалённый агент, развёртывание серверов и реальные тестовые хосты.
8. Проверка всех сценариев ACCEPTANCE.md, мобильная полировка, установщики, подпись и дистрибуция.

## Внешние зависимости

Discord client credentials, публичный HTTPS callback и сервер; реальные пользователи и CS2-демки; права на распространяемые карты/медиа; тестовый CS2/TeamSpeak хост; macOS/Xcode и Apple signing; Android SDK и Windows C++ toolchain. Отсутствие зависимости не считается успешной проверкой.
