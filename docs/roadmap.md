# Roadmap / Планы

## Available in 0.95 Beta

Windows and Android clients; English/Russian UI; account-based teams and roles; shared tactics, maps and utility materials; durable synchronization queue; task review history; typed training plans, deadlines and criteria; map preparation templates; Windows demo tools and PDF playbooks.

## Next

- Training evidence and independent comments / доказательства выполнения и отдельные комментарии.
- Scheduling, attendance and push notifications / расписание, посещаемость и уведомления.
- Live joint review / совместный живой разбор.
- Remote bootcamp agent / удалённый серверный агент.
- Complete offline review/history bundles / полные офлайн-пакеты.
- Migration assistance for older manually assigned players without account links / перенос старых назначений на реальные аккаунты.
- Broader Steam, real CS2, TeamSpeak and physical Android acceptance.

This is a scope list, not a promised delivery schedule. See [acceptance](acceptance.md).
