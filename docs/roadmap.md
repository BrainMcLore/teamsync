# Roadmap / Планы

## Available in 1.0.0

Windows and Android clients; English/Russian UI; account-based teams and roles; shared tactics, maps and utility materials; durable synchronization; task discussion, evidence and coach review; typed training plans and map preparation templates; schedule, RSVP and attendance; local reminders and team workload snapshots; portable demo reviews and tactic history; online-team backup restoration; Windows demo tools, PDF playbooks and local bootcamp controls.

The older 0.95 Beta download remains immutable. Release 1.0.0 publishes the current baseline with the [known limitations and acceptance evidence](release-audit.md).

## Next / Далее

- Reliable live HLTV archive delivery and broader external-source acceptance.
- Cloud push notifications / облачные push-уведомления.
- Live joint review / совместный онлайн-разбор.
- Authenticated remote bootcamp agent / защищённый удалённый серверный агент.
- Review edit/deletion audit and complete portable history / журнал правок и удалений заметок.
- Broader Steam, real CS2, TeamSpeak and physical Windows/Android acceptance.

This is a scope list, not a promised delivery schedule. See [follow-up acceptance](full-release.md).
